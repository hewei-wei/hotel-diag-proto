# 酒店新媒体营销平台 · 抖音来客诊断

交互原型与产品需求文档（PRD）协作仓库。

## 在线访问

- 交互原型：<https://hewei-wei.github.io/hotel-diag-proto/>
- PRD：点击仓库中的 `酒店新媒体营销平台_诊断需求PRD_v0.1.md`，GitHub 自动渲染预览

## 修改方式

1. 打开仓库页面，按键盘 `.` 进入网页编辑器（VS Code 网页版）
2. 修改 `index.html`（原型）或 PRD 文档
3. `Ctrl+S` 保存，填写提交说明后点 **Commit & Push**
4. 约 1 分钟后刷新在线访问链接，即可看到最新版本
